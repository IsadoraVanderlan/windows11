# 💻 Aula 01: Conhecendo o Sistema Operacional (Windows 11)

Nesta primeira aula, o foco foi compreender os conceitos fundamentais do Windows 11, explorando sua nova interface gráfica e os elementos essenciais de navegação do sistema operacional.

---

### 1. O que é um Sistema Operacional?

- É o software principal que gerencia todo o hardware do computador.
- Serve como a ponte de comunicação entre o usuário e a máquina.

### 2. A Nova Interface do Windows 11

- **Menu Iniciar Centralizado**: Diferente das versões anteriores, os ícones do menu iniciar e da barra de tarefas ficam centralizados por padrão para facilitar o foco.
- **Conceito de Janelas (Windows)**: O sistema é baseado em janelas flutuantes que permitem a execução de múltiplas tarefas ao mesmo tempo (multitarefa).
- **Área de Trabalho (Desktop)**: O espaço principal onde ficam os papéis de parede, atalhos de programas e arquivos mais utilizados.

---

## 🛠️ Prática Realizada

1. Exploração do novo layout do Menu Iniciar e dos aplicativos fixados.
2. Manipulação de janelas (abrir, maximizar, minimizar e fechar).
3. Organização inicial de ícones na Área de Trabalho.
